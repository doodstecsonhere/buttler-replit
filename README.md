# Buttler — Bidet and Restroom Finder

Buttler is a mobile-first progressive web app for discovering bidets and restrooms in Dumaguete City, Philippines.

## Highlights

- Interactive map of restroom locations
- Search and filters for bidet availability and public access
- Directions, access details, fees, and verification status
- Guardian audit workflow for community verification
- Offline-capable PWA experience

## Technology

React, TypeScript, Vite, Leaflet/OpenStreetMap, Express, PostgreSQL, Drizzle ORM, and pnpm workspaces.

## Repository status
