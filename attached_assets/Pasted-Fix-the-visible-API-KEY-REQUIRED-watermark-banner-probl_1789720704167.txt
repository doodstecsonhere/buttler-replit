CURRENT PROBLEM

The current Replit version of Buttler uses a CARTO basemap/tile endpoint that now displays repeated diagonal:

"API KEY REQUIRED"

watermarks across the map.

The map itself works, but these watermarks make the application look broken and must be eliminated.

Use that implementation as the reference architecture.

REFERENCE FIX FROM THE INDEPENDENT BUTTLER VERSION

The old problematic Leaflet tile layer used:

https://{s}.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}{r}.png

The independent Buttler repository removed CARTO entirely and replaced it with the standard OpenStreetMap online tile endpoint:

https://tile.openstreetmap.org/{z}/{x}/{y}.png

with proper visible OpenStreetMap attribution.

The reference implementation essentially uses:

const OSM_TILE_URL =
  'https://tile.openstreetmap.org/{z}/{x}/{y}.png';

const OSM_ATTRIBUTION =
  '&copy; <a href="https://www.openstreetmap.org/copyright" target="_blank" rel="noopener noreferrer">OpenStreetMap</a> contributors';

and the Leaflet TileLayer uses that URL and attribution instead of CARTO.

The independent implementation also:

1. Removes CARTO attribution.
2. Removes all cartocdn/CARTO tile references.
3. Does NOT require an API key, account, payment card, trial, or paid map provider.
4. Does not service-worker-prefetch or persist third-party map tiles.
5. Keeps the existing Leaflet map, restroom markers, bidet markers, marker popups, user-location marker, pan, zoom, and geolocation functionality.
6. Gracefully handles tile/network failure without breaking the restroom-location functionality.
